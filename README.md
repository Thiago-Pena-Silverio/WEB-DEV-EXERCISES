# WEB-DEV-EXERCISES
Web Development exercises collection from the Web Development module - university assignments

> ⚠️ **Note:** This project was developed for academic purposes and the content is written in Portuguese.

---

**Name of the repository:** Web Dev Exercises

🎓 **Context:**

A collection of exercises developed during the Web Development module, covering fundamental topics such as CSS styling, JavaScript logic, and Bootstrap framework. Each folder represents a different topic practiced throughout the course.

📁 **Folders:**

**Aleatory Styles:** CSS exercises using various selectors and styling techniques, including themed pages for Final Fantasy, Mario, and Metal Gear Solid

**JS Condicionais:** JavaScript exercises focused on conditional logic using if/else statements

**JS Repetições:** JavaScript exercises focused on loops and iteration, including a multiplication table generator

**Functions:** JavaScript exercises focused on building and calling functions, including form interactions and input validation

**Bootstrap PW:** Exercise building a profile/portfolio page using the Bootstrap framework

🛠️ **Tech Stack:**

- HTML5
- CSS3
- JavaScript
- Bootstrap

🎖️ **Features:**

- CSS selector combinations and styling 🎨

- JavaScript conditionals and validation ✅

- JavaScript loops and iteration 🔁

- JavaScript functions and DOM manipulation 🧩

- Bootstrap responsive layout 📱

---

🖥️ **How to Run**

**Requirements:**

- Any modern web browser (Chrome, Firefox, Edge, etc.)
- No installation needed

**Instructions:** 💾

1. Download: Click on Code → Download ZIP
2. Extract: Unzip the file WEB-DEV-EXERCISES-main.zip
3. Navigate to the desired folder and open the `.html` file
4. The page will open automatically in your default browser
